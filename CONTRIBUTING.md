# Contribuindo com o PlantSync

1. Crie uma branch a partir da `main`.
2. Nunca versione credenciais (veja o `.gitignore` e o RNF02).
3. Rode os testes do backend antes de abrir o PR: `cd back_end && pytest`.
4. Escreva mensagens de commit curtas, no imperativo e em português.
5. Abra um Pull Request descrevendo o que mudou e como testar.
